# FGO · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **进入游戏**：进入游戏主界面
- **领取邮箱奖励**：进入邮箱，一键领取所有邮件奖励（除卡牌外内容）
- **刷体力**：消耗体力进行战斗
- **领取任务奖励**：领取所有已完成的任务奖励
- **免费友情点召唤**：进入友情点卡池，执行每日免费的10连友情点召唤
- **免费召唤**：进入剧情卡池，执行每日免费的剧情召唤
- **重复刷关卡**：连续重复刷同一关卡，直到体力不足或任务结束（使用时右下角应该有开始任务字符！）
- **自动推图**：自动推进主线/活动关卡，包括选择关卡、跳过剧情、战斗、助战选择等全流程；但是bug很多

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
