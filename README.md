# FGO · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

- 🗡️ 刷本：从你预设的助战列表里取**第一个**助战，一直刷到体力耗尽
- 📋 领取每日任务奖励、✉️ 邮箱奖励
- 🔮 使用每天的免费 10 次召唤

> 注意：刷本前请提前把助战顺序改成你想要的（推荐按攻击力排序），并选择打得过的关卡——脚本没有作战失败处理。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
